# Archived documentation — prototype v0.1

> **Historical record. Not current product documentation.**

These documents describe the original single-institution prototype, then called "Smart Campus Intelligence"
(later developed as RIO, now **ACEDRA**). They are kept for project history only and are **out of date**:
v0.1 had no multi-tenancy, allowed anonymous chatbot use, described hashed-token retrieval as "semantic
embeddings" and shipped incomplete migrations. Screenshots in `screenshots/` show the retired v0.1 interface.

Current documentation: `../ARCHITECTURE.md`, `../SECURITY_AND_RBAC.md`, `../DEPLOYMENT_GUIDE.md`,
`../KNOWN_LIMITATIONS.md` and the repository `README.md`.
